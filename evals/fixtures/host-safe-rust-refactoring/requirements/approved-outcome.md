# Approved Host-Safe Validation Outcome

Authority: approved

An ordinary developer or automated check can run one representative diagnostic
exchange without Docker, privileged paths, system D-Bus, shell sleeps, or
name-based process cleanup.

The validation system must select one isolated setup, start the required UDS
and DoIP services, report readiness only when the complete path can accept the
request, execute the diagnostic exchange through the public client boundary,
and stop every owned task and resource after success or failure.

Focused component checks remain useful. They do not complete this outcome
without the representative vertical flow. Hardware, CAN, privileged-network,
and external-vehicle checks remain human-owned.
