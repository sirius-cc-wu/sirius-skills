# User Stories: Split Install Modes

- **SIM-01 (M)**: As a local contributor, I want a source-linked install
  path so that my repo checkout is the runtime source of truth.
- **SIM-02 (L)**: As a maintainer, I want packaged install commands separated
  from source-linked local install commands so that distribution concerns do
  not shape day-to-day development.
- **SIM-03 (L)**: As a maintainer, I want shared-runtime sync and installed
  parity checks scoped to packaged/export boundaries so that local maintenance
  flows stay simple and deterministic.
- **SIM-04 (M)**: As a contributor, I want migration guidance and compatibility
  steps so that I can move from the current install model without breaking my
  workflow.
