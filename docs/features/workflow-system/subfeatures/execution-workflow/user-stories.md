# User Stories: Execution Workflow

- **EW-01 (M)**: As a maintainer, I want to bootstrap one slice per work item so that execution stays slice-scoped and traceable.
- **EW-02 (L)**: As a slice definer, I want to capture a brief and requirements checklist so that implementation starts from testable intent.
- **EW-03 (L)**: As a planner, I want to produce a concrete execution plan with gates and validation so that coding can proceed without major replanning.
- **EW-04 (L)**: As a reviewer and closer, I want to review, relate, and close slices non-destructively so that execution history stays durable.
