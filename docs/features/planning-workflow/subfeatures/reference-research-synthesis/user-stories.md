# User Stories: Reference Research Synthesis

- **RRS-01 (M)**: As a planner, I want an explicit reference-research step for
  features that overlap checked-in upstream patterns so that discovery does not
  rely only on memory or one default tutorial path.

- **RRS-02 (M)**: As a maintainer, I want reusable cross-reference conclusions
  written into the repository wiki layer so that future features can reuse the
  same synthesis instead of re-deriving it from raw repos every time.

- **RRS-03 (M)**: As a reviewer, I want planning artifacts to record the chosen
  borrowing path and its tradeoffs so that design and review decisions are
  inspectable after the chat session ends.

- **RRS-04 (S)**: As a repository adopter, I want the workflow to require
  reference research only when it is materially relevant so that the planning
  process stays useful without becoming unnecessary ceremony for local-only
  changes.
