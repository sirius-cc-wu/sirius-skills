# User Stories: Planning Workflow

- **PW-01 (M)**: As a feature lead, I want to initialize a feature planning folder so that planning state and artifacts are durable in the repository.
- **PW-02 (L)**: As a planner, I want explicit discovery and design readiness gates so that architecture and decomposition start from concrete intent.
- **PW-03 (L)**: As a breakdown owner, I want to split stories into execution-ready slices and increments so that later work can bootstrap execution tracks safely.
- **PW-04 (M)**: As a reviewer, I want planning readiness and handoff metadata recorded durably so that task bootstrap does not rely on chat memory.
