# User Stories: Installation and Configuration

- **IC-01 (M)**: As a maintainer, I want one managed install/uninstall path so that the shared skills can be registered consistently.
- **IC-02 (M)**: As a project owner, I want separate planning and execution layout configs so that repository structure stays explicit.
- **IC-03 (M)**: As a project owner, I want naming and ID conventions in a dedicated config file so that core skills stay generic.
- **IC-04 (L)**: As an extension author, I want a documented plugin convention so that project-local logic can be added without polluting shared skills.
