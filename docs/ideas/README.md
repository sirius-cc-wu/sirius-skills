# Ideas

This directory contains candidate-direction documents and their implementation
rationale. New candidate directions use `idea-refine`; save the confirmed
one-pager here after user confirmation.

The directory also contains documents migrated from the former Sirius proposal
location. Those documents retain their historical content and links. Do not
create a second candidate artifact for the same direction.

Iteration records live in [`iterations/`](iterations/). They preserve risk,
scope, exit criteria, and results during delivery and after closure. They do not
define the active capability contract.
