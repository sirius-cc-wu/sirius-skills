# User Stories: Workflow Capability Upgrades

- **WCU-01 (M)**: As a repository maintainer, I want a project-principles or
  constitution capability so that planning and review skills can rely on a
  durable statement of repo expectations.

- **WCU-02 (M)**: As a planner, I want a dedicated clarification capability so
  that high-impact ambiguities are resolved in repo artifacts before design and
  breakdown.

- **WCU-03 (L)**: As a project adopter, I want richer project-level planning
  context and rule customization so that core skills can adapt to local
  conventions without losing their generic-first defaults.

- **WCU-04 (L)**: As a planning reviewer, I want stronger verification and
  reconciliation patterns for planning artifacts so that readiness review can
  detect drift, inconsistency, and missing cross-artifact alignment earlier.

- **WCU-05 (L)**: As a maintainer, I want the new capabilities to fit the
  existing `guide-planning -> discover -> design -> breakdown -> review-planning
  -> slice` route so that the current planning and slice model stays coherent.
