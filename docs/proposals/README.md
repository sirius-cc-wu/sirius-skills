# Proposals

This directory contains capability proposals and their implementation rationale;
the documents themselves are not deployable skills. A proposed capability
remains non-normative until it is implemented and cataloged. After
implementation, the active skills, catalog, and workflow tracks are
authoritative while the proposal preserves rationale and delivery history.

Proposal-scoped iteration records live in [`iterations/`](iterations/). They
preserve risk, scope, exit criteria, and results during delivery and after
closure without becoming the active capability contract.
