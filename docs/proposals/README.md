# Legacy Proposals

This directory preserves Sirius capability proposals and their implementation
rationale from earlier workflows. These documents are not deployable skills.

Use `idea-refine` for new candidate directions. Save the confirmed idea
one-pagers under `docs/ideas/` or a feature path defined by local governance. Do
not create new proposal artifacts.

Existing proposal files remain at their historical paths. Preserve them because
links and iteration records depend on those paths. A proposal remains
non-normative until the capability is implemented and, when deployable,
cataloged. After implementation, active code, skills, evals, the catalog, and
workflow tracks are authoritative. The legacy proposal preserves rationale and
delivery history.

Proposal-scoped iteration records live in [`iterations/`](iterations/). They
preserve risk, scope, exit criteria, and results during delivery and after
closure. They do not define the active capability contract.
